# Fonts

- `nerdworkbench/` — NerdWorkbench Mono (text + pixel icons) and NerdWorkbench
  Icons, generated by `tools/build-fonts.py`. Sources, grid, licences and
  publication status: [../../FONTS.md](../../FONTS.md).
- `unicode/` — the vendored Topaz Unicode input (ISC), see `SOURCE.json`.

The earlier GPL-FE "Multi Platform Amiga Fonts" Topaz files are no longer
shipped; they remain only in this repository's history.
